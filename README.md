# Providence Spaceliners — independent design concept

A speculative redesign of [providencespaceliners.com](https://providencespaceliners.com/),
built as a scroll-driven 3D site.

**This is not an official Providence Spaceliners property.** It is an unsolicited design
concept produced by MainState Labs. It is not affiliated with, authorised by, or endorsed
by Providence Spaceliners Corporation. Company name, copy, imagery and likenesses belong
to their respective owners and are reproduced here only to present the design proposal.
The site is served with `noindex` and a `robots.txt` disallow so it cannot be confused
with the live site in search results.

Aircraft renders are design concepts generated for this proposal. They do not depict
hardware that exists.

Source and build tooling: see the full project README in the design repository.
